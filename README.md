## NextIn

NextIn is a virtual queue app for customers and business staff, built with Kotlin, Jetpack Compose, and Material 3

### Things done so far:
- Welcome screen with temporary customer/staff selection
- Customer home placeholder
- Staff dashboard placeholder
- Navigation Compose routing and base Material 3 theme

### Open and run
1. Unzip this folder and open NextIn in Android Studio
2. Use Android Studio's embedded JDK 17 or 21 and install Android SDK 35
3. Allow Gradle sync, then run the `app` configuration on an emulator


### Not implemented yet
Firebase, real queue management, data models, local persistence, notifications, and the Wear OS (Watch)
